# TripAtlas 🌍

TripAtlas is an all-in-one travel super-app designed to simplify trip planning, booking, and navigation in a single platform. It combines transportation, lodging, discovery, safety tools, and real-time travel data into one seamless experience.

---

## 📌 GitHub Short Description (≤300 characters)

TripAtlas is an all-in-one travel super-app for planning trips, booking transport & hotels, discovering places, and managing safety, weather, and costs in one platform.

---

## 🚀 Overview

TripAtlas helps users plan, manage, and experience travel more efficiently by combining multiple services into one platform:

- Flights, buses, trains, and car rentals  
- Hotels and stays  
- Maps and navigation  
- Attractions and local discovery  
- Restaurants and businesses  
- Emergency and safety resources  
- Real-time weather and alerts  
- Trip budgeting and cost tracking  

---

## ✨ Features

### 🧭 Trip Planning
- Full itinerary builder  
- Multi-stop routes  
- Round-trip management  

### 🚗 Transportation
- Flight and bus search integration  
- Car rentals and ride-share options  
- Fuel, toll, and parking cost estimates  

### 🏨 Lodging
- Hotel comparisons  
- Budget filtering  
- Location-based suggestions  

### 🍽️ Local Discovery
- Restaurants and food spots  
- Attractions and scenic places  
- Real-time open/closed status  

### 🛡️ Safety Tools
- Emergency contacts directory  
- Nearby hospitals and clinics  
- Future: crime & safety heatmaps  

### 🌦️ Live Data
- Weather updates  
- Travel alerts  
- Location-based recommendations
